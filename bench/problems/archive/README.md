# Archived problem versions

Legacy 1-D / untested-2-D problem versions, kept for provenance. These
modules (`p1_off_axis_quad_v1.py`, `p2_rosenbrock_v1.py`, `p3_saddle_v1.py`,
`p5_div_backward_v1.py`) carry `name = ""`, are not registered in the problem
registry, and are imported by nothing. They are superseded by the
matrix-version problems in the parent directory (`bench/problems/`), which are
the versions used by the benchmark sweep and the paper figures. They are
retained here only to document how the problem set evolved.
